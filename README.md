# 🎮 显卡价格趋势监控 (GPU Price Tracker)

实时追踪主流 40 系和 50 系显卡的价格走势，拒绝黄牛溢价，用数据看清真实行情。

## ✨ 项目特色
- **极简高级商务风**：干净的 UI 设计，毫无广告干扰。
- **多折线同屏对比**：直观展示不同型号显卡的历史价格波动。
- **全自动云端更新**：基于 GitHub Actions，每天定时自动抓取最新数据。

## 🛠️ 技术栈
- **数据抓取**：Python
- **前端展示**：HTML + ECharts
- **自动化部署**：GitHub Actions
